# MediQueue — Hospital Queue Management System

MediQueue is a full-stack web application designed to
simplify hospital appointments and patient queue management.

## Main Features
- Patient registration and login
- Hospital search
- Doctor availability
- Appointment booking
- Digital queue tokens
- Live queue tracking
- Hospital staff dashboard

## Tech Stack
- Frontend: React
- Backend: Node.js and Express
- Database: MongoDB
- Version Control: Git and GitHub
